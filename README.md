# Stellar Burgers

Stellar Burgers — одностраничное приложение космической бургерной, в котором пользователи могут собирать собственные бургеры, оформлять заказы, просматривать общую ленту заказов и историю своих заказов. Проект разработан на React с использованием Redux Toolkit и TypeScript.

## Возможности приложения

- просмотр списка ингредиентов;
- конструктор бургеров с поддержкой Drag & Drop;
- оформление заказа;
- регистрация и авторизация пользователей;
- редактирование данных профиля;
- просмотр истории заказов;
- общая лента заказов в режиме реального времени;
- защищённые маршруты;
- модальные окна с поддержкой прямых ссылок;
- покрытие бизнес-логики и пользовательских сценариев тестами.

## Стек технологий

## Маршруты

| Маршрут | Описание |
|---|---|
| `/` | Главная страница с конструктором бургеров |
| `/feed` | Лента всех заказов |
| `/login` | Авторизация |
| `/register` | Регистрация |
| `/forgot-password` | Восстановление пароля |
| `/reset-password` | Смена пароля |
| `/profile` | Профиль пользователя |
| `/profile/orders` | История заказов пользователя |
| `/ingredients/:id` | Информация об ингредиенте |
| `/feed/:number` | Информация о заказе из общей ленты |
| `/profile/orders/:number` | Информация о заказе пользователя |
| `*` | Страница 404 |

Маршруты `/profile`, `/profile/orders` и `/profile/orders/:number` доступны только авторизованным пользователям.

## Основной функционал

### Конструктор бургеров

- просмотр ингредиентов;
- добавление ингредиентов в конструктор;
- изменение порядка ингредиентов;
- подсчёт стоимости;
- оформление заказа.

### Авторизация

- регистрация пользователя;
- вход в систему;
- выход из аккаунта;
- восстановление пароля;
- обновление профиля.

### Лента заказов

- получение заказов через WebSocket;
- отображение общей статистики;
- просмотр информации о заказе;
- расчёт стоимости каждого заказа.

### Личный кабинет

- просмотр информации о пользователе;
- редактирование профиля;
- история заказов;
- просмотр деталей каждого заказа.

## Тестирование

В проекте реализованы два вида тестирования.

### Jest

Покрыты тестами:

- reducers;
- actions;
- async thunk;
- обработка состояний `pending`, `fulfilled` и `rejected`.

### Playwright

Проверяются пользовательские сценарии:

- открытие страницы конструктора;
- добавление ингредиентов;
- открытие и закрытие модальных окон;
- оформление заказа;
- очистка конструктора после успешного оформления заказа.

## Как запустить проект локально

1. Клонировать репозиторий:

   ```bash
   git clone https://github.com/<ваш_логин>/stellar-burgers.git
   cd stellar-burgers
   ```

2. Установить зависимости:

   ```bash
   npm install
   ```

3. Создать файл `.env`:

   ```env
   BURGER_API_URL=https://norma.nomoreparties.space/api
   ```

4. Запустить приложение:

   ```bash
   npm run dev
   ```

После запуска приложение будет доступно по адресу:

```
http://localhost:5173
```
